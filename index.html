如何讓 40 位學生用手機填 Google 表單，大富翁一秒自動抓題？

  1. 建立一個 Google 表單，設定 4 個欄位：① 組別暱稱、② 關卡格號 (0~15)、③ 題目文字、④ 圖片網址 (選填)。
  2. 打開表單連結的「Google 試算表」，點選左上角 「檔案 ➔ 共用 ➔ 發佈到網路」。
  3. 選擇 「逗號分隔值 (.csv)」 並複製網址貼到下方，上課時按一下就能把全班手機提交的題目全部同步進來！

GitHub Pages / Vercel 極速部署 ＋ Google Apps Script 免費雲端資料庫

1. 部署前端網頁：將本檔案存為 index.html 上傳至 GitHub Repository，開啟 Settings ➔ Pages（或匯入 Vercel），10 秒即可產生專屬網址（如 https://khtatung-monopoly.vercel.app）。

2. 綁定 Google 雲端試算表自動存檔：在您的 Google 試算表點選 「擴充功能 ➔ Apps Script」，貼上下方 15 行程式碼並點選「部署為網頁應用程式（所有人皆可存取）」，把網址貼回下方即可在 Vercel 上永久保存進度！

📋 Google Apps Script 雲端存取程式碼（貼入 Google 試算表即可當免費後端）： 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("State") || SpreadsheetApp.getActiveSpreadsheet().insertSheet("State");
  sheet.getRange("A1").setValue(e.postData.contents);
  sheet.getRange("B1").setValue(new Date());
  return ContentService.createTextOutput(JSON.stringify({status:"ok"})).setMimeType(ContentService.MimeType.JSON);
}
function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("State");
  var data = sheet ? sheet.getRange("A1").getValue() : "{}";
  return ContentService.createTextOutput(data).setMimeType(ContentService.MimeType.JSON);
}
